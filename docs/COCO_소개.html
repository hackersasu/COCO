COCO(코코)는 스마트폰을 쓰는 어르신을 위한 작은 파란 점 조수예요. "코코야~" 하고 부른 뒤 하고 싶은 일을 편하게 말하면, 코코가 그 말을 폰의 기능으로 바꾸고 다음에 누를 곳을 점 하나로 가리켜요. 대신 눌러 주지 않아요. 어르신이 직접 누르면서 폰을 익혀요.

문제

어디를 눌러야 할지 모르는 순간

손주들이 뉴진스 이야기를 할 때, 우리는 바로 검색해요. 어르신은 어디에 검색해야 하는지, 검색이라는 기능이 있는지부터 막혀요. 앱마다 무슨 기능이 있는지 모르는 상태에서 하고 싶은 일이 생기면, 그 일을 조작으로 바꾸는 단계에서 멈추게 돼요.

"틀릴까 봐 무섭다"

잘못 누르면 뭔가 망가질 것 같아서 시도 자체를 안 해요.

"남한테 묻기 미안하다"

자녀나 손주에게 같은 걸 또 묻는 게 부담스러워요.

"혼자 해내고 싶다"

대신 해 주는 것보다 스스로 할 수 있게 되는 걸 원해요.

그래서 코코는 대신 해 주지 않아요. 가장 덜 방해되는 크기의 점으로 다음 한 걸음만 보여 주고, 누르는 건 어르신 몫으로 남겨요. 자기 주체감을 지키는 것이 설계의 출발점이에요.

작동 방식

부르고, 말하고, 점을 따라 누르기

  1. 부르기"코코야~" 하고 부르면 깨어나요. 해커톤에서는 화면 가장자리의 작은 코코 버튼으로 대체할 수 있어요.
  2. 듣기Android 기본 음성 인식으로 한국어 발화를 텍스트로 바꿔요.
  3. 이해AI가 두서없는 말을 미리 정의한 기능 목록 중 하나에 연결하고, 필요한 정보(대상, 검색어 등)를 뽑아요.
  4. 안내코드에 정의된 단계별 스크립트가 현재 화면의 버튼을 찾아 파란 점을 띄워요. 점은 터치를 막지 않아요.
  5. 목표 유지전화가 와도 목표를 기억하고, 돌아오면 다음 단계를 다시 가리켜요. "코코야 그만"이라고 할 때만 멈춰요.

이해 단계에서 AI가 돌려주는 결과 예시:

{"capability": "YT_SEARCH",
 "slots": {"query": "뉴진스 무대"},
 "confidence": 0.91,
 "reason": "뉴진스 = K-pop 그룹 → 글보다 영상이 이해하기 쉬움 → 유튜브",
 "say": "뉴진스는 아이돌 그룹이에요. 유튜브에서 무대를 볼까요?",
 "ask": null}
핵심

어르신의 말을 폰의 기능으로 번역하는 엔진

각 앱이 해 줄 수 있는 기능은 코드에 하드코딩하고, AI는 음성을 듣고 그중 가장 관련 깊은 기능 하나를 고르는 일만 해요.

믿을 수 있어요

AI는 목록 안에서만 고르기 때문에 없는 기능을 지어낼 수 없어요. 실행은 정해진 스크립트가 맡아요.

빠르고 싸요

분류 한 번이면 되어서 gpt-4o-mini로 충분해요. 응답도 1초 안팎이에요.

자산이 선명해요

"어르신 말 → 폰 기능" 사전과 이를 고르는 엔진이 코코의 본체예요. 앱, OS, SDK는 이 사전을 어디에 꽂느냐의 차이예요.

확신이 낮을 때

호칭 매핑

"큰애", "손녀"가 연락처에는 실명으로 저장돼 있어요. "큰애 = 김OO" 같은 작은 프로필을 AI 입력에 같이 넣어요.

HCI · 인간공학

파란 점의 언어: 점 하나는 손가락 하나

클릭은 점이 버튼 위에 뜨는 것으로 충분해요. 나머지 동작은 횟수는 리듬으로, 시간은 차오르는 링으로, 방향과 힘은 붓펜 획의 굵기로 표현해요.

탭점이 한 번 톡 눌리듯 맥동해요.
더블탭짧은 맥동 두 번. 리듬 자체가 지시예요.
길게 누르기링이 다 차면 손을 떼면 돼요.
스크롤굵게 눌러 시작해 얇게 빠지는 붓펜 획. 사용자가 스크롤하면 멈춰요.
확대점 두 개가 벌어져요. 두 손가락이라는 뜻이에요.

그 밖에 동시 누르기(전원+볼륨)는 화면 가장자리 물리 버튼 옆에 점 두 개로, 뒤로가기 제스처는 화면 끝에서 안쪽으로 짧은 붓 획으로 보여 줘요. 완료되면 칭찬 멘트 대신 짧은 진동과 작은 효과로 끝내요.

기술 구조

안드로이드 스튜디오 → APK, AI는 API 호출

AI는 안드로이드 스튜디오 "안에서" 돌지 않아요. APK가 OpenAI API를 HTTPS로 부르는 구조라 실행 환경 문제는 없어요.

gpt-4o-mini로 충분한가

기능 목록 중 하나를 고르는 분류라 충분해요. 실제 발화로 정확도를 재 보고 부족할 때만 상위 모델을 사요. 무대용 "데모 모드" 스위치를 꼭 두세요.

개인정보 질문 대비

스크린샷이 아니라 버튼 텍스트만 보내고, 비밀번호 칸(isPassword)은 제외해요.

버튼 정보 모으기

adb shell uiautomator dump로 각 화면을 덤프해 텍스트·설명·viewId를 그대로 스크립트에 옮겨요. 데모 폰 기종 하나에 맞춰 하드코딩해요.

주의할 점

카카오톡은 스마트폰 한 대에서만 로그인이 유지되는 걸로 알려져 있어서, 에뮬레이터 로그인 시 실폰이 로그아웃될 수 있어요(확인 필요). 딥링크 바로가기는 비상용으로만 써요.

- 이름: COCO (한국어 "코코")
- 한 줄 설명: 스마트폰을 쓰는 어르신을 위한 작은 파란 점 조수
- 핵심 메시지: "You tap. COCO points the way." (누르는 건 어르신, 가리키는 건 코코)
- 작동 방식:
  1) 어르신이 "코코야~" 하고 부른다
  2) 두서없는 말을 듣는다 (예: "애들이 뉴진스 얘기하던데 그게 뭐야?")
  3) AI가 그 말을 폰 기본 앱의 기능 중 하나로 연결한다
     (뉴진스 → K-pop 그룹 → 글보다 영상이 이해하기 쉬움 → 유튜브 검색)
  4) 아주 작은 파란 점이 다음에 누를 곳을 가리킨다. 대신 눌러 주지 않는다.
     어르신이 직접 누르며 폰을 익힌다 (자기 주체감 보존, 최소 개입)
  5) 중간에 전화가 와도 목표를 잊지 않고, 끝나면 다시 다음 단계를 가리킨다
  6) 쓸수록 점이 줄어든다. 익숙해진 단계는 점이 늦게, 흐리게 나타나고 결국 혼자 해낸다
- 진짜 핵심(꼭 강조): 어르신의 두서없는 말을 폰의 기능으로 번역하는 엔진
- 또 하나의 핵심(꼭 강조): 대신 해 주는 대행형이 아니라, 어르신이 주체감을 갖고 직접 익혀서
  나중에는 혼자서도 할 수 있게 돕는 교육형 조수
- 확장성: 지금은 앱 → 폰 제조사용 내장 OS 기능 → 금융·보험사용 SDK
- 지원 앱: 카카오톡, 카카오맵, 유튜브, 갤러리, 카메라, 전화(음성·영상), 문자, 설정

2단계 · 스토리보드 승인 후 구현
승인한 다음에 넣어요.
승인한 스토리보드를 기반으로 Remotion 프로젝트를 구현해 줘.
프로젝트 생성부터 설치까지 네가 터미널에서 직접 진행해 줘.

요구사항:
1. 각 장면을 독립적인 React 컴포넌트로 구성
2. 전체 영상은 하나의 Composition(ID: CocoDemo)으로 연결
3. 모든 애니메이션은 Remotion의 useCurrentFrame, interpolate, spring 등을 사용
4. 장면 전환은 부드럽고 자연스럽게 구현
5. 텍스트와 UI 요소는 실제 영상에서 깨지지 않도록 구현 (한글 폰트 로딩 확인)
6. 각 장면의 시작과 종료 프레임을 한 파일(timeline 상수)에서 명확히 관리
7. 디자인 시스템(색, 폰트, 크기, spring 값)을 한 파일로 분리해 재사용
8. 폰 녹화 영상은 <OffthreadVideo>로 넣고, 파일이 없을 때는 자리표시 화면이 보이도록
   상단 상수(USE_RECORDINGS = false)로 전환할 수 있게 해 줘
9. 파란 점 위치(x, y)와 등장 프레임을 장면별 상수로 빼서, 내가 녹화본에 맞춰 숫자만 바꾸면 되게 해 줘

CSS transition이나 CSS keyframes에 의존하지 말고
Remotion의 프레임 기반 애니메이션을 사용해 줘.

구현이 끝나면 Remotion Studio(npx remotion studio)에서 미리보기 할 수 있도록 해 주고,
내가 수정해야 할 숫자들이 어느 파일 몇째 줄에 있는지 정리해 줘.
